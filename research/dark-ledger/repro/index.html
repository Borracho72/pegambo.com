PHASE VORTICES IN THE BERRY RANDOM-WAVE MODEL
This package independently reproduces known statistics of an isotropic 2D
monochromatic complex Gaussian wave. Comparisons with the first edition
of the note are in the correction table in the note itself.

RUN
  python -m venv .venv
  source .venv/bin/activate
  python -m pip install -r requirements.txt
  python reproduce.py --smoke
  python reproduce.py

On Windows PowerShell, use .\.venv\Scripts\Activate.ps1 to activate the
environment. The smoke run exercises the full pipeline on small windows.
Its output in smoke_output/ is not a statistical reproduction. The full
run saves new results, logs and regenerated point sets in reproduced/.
Use --output-dir DIR to change the destination, or --reuse-fields to
reanalyze fields already generated there. The shipped results and logs
are not overwritten. Raw point sets are not included in this package.

METHOD
The reference run uses 64 fields, 640 planar modes and 463,113 detected
zeros in analysis windows of side 48 wavelengths, surrounded by a guard
zone of 3 wavelengths. Plaquette phase winding identifies vortices.
The grid steps are 0.10, 0.05 and 0.025 wavelengths; 32 of the same fields
are checked at 0.0125. Newton refinement uses the original wave sum.
The overlay experiment pools zero coordinates, not complex amplitudes.
Uncertainties below are one bootstrap standard error, over realizations
or, for the overlay analysis, eight independent blocks of realizations.

REFERENCE RESULTS
  Same-sign asymptote: g_same(r) ~ 1.80451063 (r/lambda)^3 as r -> 0.
  At r = 0.1 lambda: g_same = 0.00192375 (theory).
  For 0.09 <= r/lambda < 0.11: 0.00241 +/- 0.00079 (verified roots).
  Opposite-sign nearest neighbour: 78.712%, SE 0.071 percentage points
  (one directed link per zero).
  Nearest-neighbour mode, irrespective of sign: 0.4574 +/- 0.0025 lambda.
  Mode for links whose actual nearest neighbour has opposite sign:
  0.4189 +/- 0.0042 lambda.
  Overlays (m = 1, 2, 4, 8), KS distance to the matching Poisson
  nearest-neighbour CDF: 0.3402 +/- 0.0006, 0.1105 +/- 0.0011,
  0.0490 +/- 0.0012, 0.0237 +/- 0.0006. At fixed r/lambda,
  the population pair-correlation excess g_m(r)-1 is (g_1(r)-1)/m.

LIMITS
The simulation is an idealized null model, not apparatus data. Small
same-sign distances have few counts and are sensitive to grid spacing,
binning and zero verification. Modes depend on sign selection and
smoothing. Finite overlays are not exactly Poisson, and measured
distances to Poisson depend on the metric and normalization.

REFERENCES
Berry & Dennis (2000), pair correlations, density and ring spectrum:
https://doi.org/10.1098/rspa.2000.0602
Shvartsman & Freund (1994), nearest-neighbour sign anticorrelation:
https://doi.org/10.1103/PhysRevLett.72.1008
Saichev, Berggren & Sadreev (2001), nearest-neighbour distances:
https://arxiv.org/abs/nlin/0012019
Dennis (2001), partial pair correlations and their short-distance limit:
https://eprints.soton.ac.uk/29376/1/SPIE4403_13.pdf

ФАЗОВЫЕ ВИХРИ В МОДЕЛИ СЛУЧАЙНОЙ ВОЛНЫ БЕРРИ

Пакет независимо воспроизводит известные статистики двумерной
изотропной монохроматической комплексной гауссовой волны. Сравнение
с первой редакцией заметки приведено в таблице исправлений самой заметки.

ЗАПУСК
  python -m venv .venv
  source .venv/bin/activate
  python -m pip install -r requirements.txt
  python reproduce.py --smoke
  python reproduce.py

В Windows PowerShell активация: .\.venv\Scripts\Activate.ps1. Быстрый
прогон проверяет весь конвейер на малых окнах; числа в smoke_output/
не заменяют полноценный расчёт. Полный прогон сохраняет новые результаты,
журналы и множества нулей в reproduced/. Папку можно изменить через
--output-dir DIR; --reuse-fields повторно анализирует уже созданные там
поля. Поставляемые результаты и журналы не перезаписываются. Исходные
множества нулей в пакет не включены.

МЕТОД
В контрольном прогоне 64 поля, 640 плоских мод, 463 113 обнаруженных
нулей. Сторона окна анализа равна 48 длинам волны, защитная полоса
равна 3 длинам волны. Вихри найдены по обходу фазы по ячейке сетки.
Шаги сетки 0.10, 0.05 и 0.025 длины волны; 32 из тех же полей проверены
также при шаге 0.0125. Уточнение Ньютона использует исходную сумму волн.
При наложении объединяются координаты нулей, не комплексные амплитуды.
После знака «±» указана одна бутстреп-стандартная ошибка по реализациям,
а при наложении полей она рассчитана по восьми независимым блокам.

КОНТРОЛЬНЫЕ РЕЗУЛЬТАТЫ
  Одноимённые пары: g_same(r) ~ 1.80451063 (r/λ)^3 при r → 0.
  При r = 0.1λ: g_same = 0.00192375 (теория).
  При 0.09 ≤ r/λ < 0.11: 0.00241 ± 0.00079 (проверенные корни).
  Разноимённый ближайший сосед: 78.712%, ошибка 0.071 п.п.
  (на каждый нуль приходится одна направленная связь).
  Мода расстояния до ближайшего соседа без отбора по знаку:
  0.4574 ± 0.0025λ; у фактически разноимённых связей: 0.4189 ± 0.0042λ.
  Наложение m = 1, 2, 4, 8 полей: расстояние Колмогорова–Смирнова
  до пуассоновской функции распределения при той же интенсивности:
  0.3402 ± 0.0006; 0.1105 ± 0.0011; 0.0490 ± 0.0012; 0.0237 ± 0.0006.
  При фиксированном r/λ верно g_m(r) − 1 = [g_1(r) − 1]/m.

ОГРАНИЧЕНИЯ
Это идеализированная нулевая модель, не данные прибора. Близких
одноимённых пар мало; результат зависит от сетки, корзин и проверки
корней. Мода зависит от отбора по знаку и сглаживания. Конечное
наложение не становится точно пуассоновским; измеренное расстояние
до Пуассона зависит от метрики и нормировки.

ЛИТЕРАТУРА
Berry и Dennis (2000): корреляции, плотность и кольцевой спектр.
https://doi.org/10.1098/rspa.2000.0602
Shvartsman и Freund (1994): антикорреляция знаков ближайших соседей.
https://doi.org/10.1103/PhysRevLett.72.1008
Saichev, Berggren и Sadreev (2001): расстояния до ближайших соседей.
https://arxiv.org/abs/nlin/0012019
Dennis (2001): частичные корреляции и их предел на малых расстояниях.
https://eprints.soton.ac.uk/29376/1/SPIE4403_13.pdf

Independent check of fp16 numerical behaviour in Pythia-160M attention graphs
=============================================================================

WHAT IS MEASURED
EleutherAI/pythia-160m (revision 50f5173d932e8e61f858120bcb800b97af589f46; 12 layers x 12 heads)
is run on three probe texts (texts/: prose 172 tokens, code 233, arithmetic 181) in several
precision modes. For every layer and head we record:
 - where Inf/NaN first appears (module hooks plus instrumentation of q, k, QK^T, softmax, A@V);
 - the fraction of exact zeros and the smallest non-zero attention weights A;
 - the graph: W = (A + A^T)/2 without the diagonal, top-8 neighbours per node; the fraction of edges
   below 2^-14 with the threshold applied to A (before symmetrisation) and to W; edge agreement
   with fp32 (Jaccard); number of connected components;
 - M = log10(w_min/eps) for 5 explicit definitions of w_min and eps in {2^-14, 2^-24, 2^-126, 2^-149}.

MODES (s2_run_model.py)
 fp32              reference
 fp64_true         model.double(), softmax in fp64 (control)
 fp64              model.double() with the stock HF eager attention (its softmax runs in fp32)
 fp16              model.half(), stock HF eager attention
 fp16_puresoftmax  as fp16, softmax in fp16
 fp16_prescale     as fp16, q multiplied by the scale before the matmul
 fp16_upcastQK     fp16 model, QK^T and softmax in fp32, A stored in fp16 (isolates fp16 storage of A)
 fp16_sdpa         stock SDPA (A is not returned; only finiteness is checked)

HOW TO RUN
 pip install --index-url https://download.pytorch.org/whl/cpu torch==2.15.0
 pip install -r requirements.txt
 ./run_all.sh       full run, ~10 min on 2 CPU cores, ~2 GB RAM; raw A tensors go to raw/ (~160 MB)
 ./run_all.sh 1     step 1 only (format facts, no model download)
Environment of the published results: environment.txt (Python 3.14.8, torch 2.15.0+cpu,
transformers 5.23.0, Intel Xeon with AVX-512, 2 threads). The computation is deterministic
(eval mode, no dropout).

KEY RESULTS (results/)
1. fp16 format (s1_format_facts.json): smallest normal 2^-14 = 6.10e-5, smallest subnormal
   2^-24 = 5.96e-8, epsilon 2^-10, maximum 65504. fp16 softmax on CPU keeps subnormal values;
   exact zero only for values <= 2^-25 ~ 2.98e-8.
2. Inf/NaN (summary_nonfinite.csv, s2c_attn_internals.json, s2d_overflow_location.json): in fp16
   the unscaled q·k^T exceeds 65504 (in fp32 up to 79305 in layer 4 on prose), producing +Inf;
   softmax returns NaN, which propagates. Fully NaN: layers 5–11 (prose, code), 6–11 (arithmetic);
   layers counted from zero. fp32, fp64, fp16_upcastQK and fp16_sdpa are finite throughout;
   fp16_prescale postpones the failure to layer 10.
3. Fraction of top-8 edges below 2^-14 in layers 8–11 (s6_pooled_knife.csv; pooled over heads and
   nodes; fp64_true and fp32 agree to <= 0.5 percentage points):
      threshold on A: prose 43.2–71.7 %, code 33.7–65.8 %, arithmetic 27.4–70.8 %
      threshold on W: prose 46.3–72.6 %, code 37.2–67.2 %, arithmetic 30.2–72.2 %
   Actually zeroed when A is stored in fp16 (fp16_upcastQK): 7.9–61.8 %; the rest are kept as
   subnormals.
4. Unthresholded top-8 graphs are connected (1 component) in every layer of every finite mode
   (per_layer.csv, n_comp_top8). In NaN layers the graph is undefined; if NaN is replaced by zero,
   all edges are zero.
5. M (M_grid.csv, M_ranges.csv) varies by tens of orders of magnitude with w_min and eps.
   In fp16 with w_min = smallest non-zero weight and eps = 2^-24, M = 0.00 in every layer.

FILES
 s1…s6, run_all.sh   scripts (order and purpose listed in run_all.sh)
 texts/              probe texts
 results/per_head.csv, per_layer.csv   all metrics per (text, mode, layer, head) / per layer
 results/summary_*.csv, summary_tables.md   summary tables

LIMITATIONS
 - CPU only; GPU behaviour (including flush-to-zero modes of specific libraries) was not tested.
 - One model and one revision; three short texts (172–233 tokens), batch size 1.
 - fp16_upcastQK and fp64_true are control constructions, not stock configurations.
 - M is a diagnostic quantity; no definition of w_min is singled out as canonical.

Независимая проверка числового поведения fp16 в графах внимания Pythia-160M
============================================================================

ЧТО ИЗМЕРЯЕТСЯ
Модель EleutherAI/pythia-160m (ревизия 50f5173d932e8e61f858120bcb800b97af589f46; 12 слоёв x 12 голов)
прогоняется на трёх зондовых текстах (texts/: проза 172 токена, код 233, арифметика 181) в нескольких
режимах точности. По каждому слою и голове записываются:
 - где впервые появляются Inf/NaN (хуки на модулях и инструментация q, k, QK^T, softmax, A@V);
 - доля точных нулей и минимальные ненулевые веса внимания A;
 - граф: W = (A + A^T)/2 без диагонали, top-8 соседей на узел; доля рёбер ниже 2^-14 при пороге
   на A (до симметризации) и на W; совпадение рёбер с fp32 (Jaccard), число компонент;
 - M = log10(w_min/eps) при 5 явных определениях w_min и eps из {2^-14, 2^-24, 2^-126, 2^-149}.

РЕЖИМЫ (s2_run_model.py)
 fp32              эталон
 fp64_true         model.double(), softmax в fp64 (контроль)
 fp64              model.double() в штатном eager HF (softmax там считается в fp32)
 fp16              model.half(), штатное eager-внимание HF
 fp16_puresoftmax  как fp16, но softmax в fp16
 fp16_prescale     как fp16, но q умножается на масштаб до matmul
 fp16_upcastQK     модель в fp16, QK^T и softmax в fp32, A хранится в fp16 (изолирует хранение A в fp16)
 fp16_sdpa         штатный SDPA (веса A не выдаются; проверяется только конечность)

ЗАПУСК
 pip install --index-url https://download.pytorch.org/whl/cpu torch==2.15.0
 pip install -r requirements.txt
 ./run_all.sh       полный прогон, ~10 мин на 2 ядрах CPU, ~2 ГБ RAM; сырые A пишутся в raw/ (~160 МБ)
 ./run_all.sh 1     только шаг 1 (свойства формата, без загрузки модели)
Окружение публикуемых результатов: environment.txt (Python 3.14.8, torch 2.15.0+cpu,
transformers 5.23.0, Intel Xeon с AVX-512, 2 потока). Расчёт детерминирован (eval, без dropout).

КЛЮЧЕВЫЕ РЕЗУЛЬТАТЫ (results/)
1. Формат fp16 (s1_format_facts.json): минимальное нормальное 2^-14 = 6.10e-5, минимальное субнормальное
   2^-24 = 5.96e-8, эпсилон 2^-10, максимум 65504. Softmax в fp16 на CPU сохраняет субнормальные
   значения; точный ноль только для значений <= 2^-25 ~ 2.98e-8.
2. Inf/NaN (summary_nonfinite.csv, s2c_attn_internals.json, s2d_overflow_location.json): в fp16
   неотмасштабированное q·k^T превышает 65504 (в fp32 до 79305 в слое 4 на прозе), появляется +Inf,
   softmax даёт NaN, NaN распространяется дальше. Полностью NaN: слои 5–11 (проза, код), 6–11
   (арифметика); счёт слоёв с нуля. В fp32, fp64, fp16_upcastQK и fp16_sdpa всё конечно;
   fp16_prescale откладывает отказ до слоя 10.
3. Доля top-8 рёбер ниже 2^-14 в слоях 8–11 (s6_pooled_knife.csv; пул по головам и узлам; fp64_true
   и fp32 совпадают с точностью <= 0.5 п.п.):
      порог на A: проза 43.2–71.7 %, код 33.7–65.8 %, арифметика 27.4–70.8 %
      порог на W: проза 46.3–72.6 %, код 37.2–67.2 %, арифметика 30.2–72.2 %
   Реально обнуляются при хранении A в fp16 (fp16_upcastQK): 7.9–61.8 %; остальные хранятся
   субнормальными.
4. Графы top-8 без порога связны (1 компонента) во всех слоях во всех конечных режимах
   (per_layer.csv, n_comp_top8). В NaN-слоях граф не определён; если NaN заменить нулём, все
   рёбра нулевые.
5. M (M_grid.csv, M_ranges.csv) меняется на десятки порядков в зависимости от w_min и eps.
   В fp16 при w_min = наименьший ненулевой вес и eps = 2^-24 M = 0.00 во всех слоях.

ФАЙЛЫ
 s1…s6, run_all.sh   скрипты (порядок и назначение — в run_all.sh)
 texts/              зондовые тексты
 results/per_head.csv, per_layer.csv   все метрики по (текст, режим, слой, голова) / по слоям
 results/summary_*.csv, summary_tables.md   сводные таблицы

ОГРАНИЧЕНИЯ
 - Только CPU; поведение на GPU (в т.ч. режимы flush-to-zero конкретных библиотек) не проверялось.
 - Одна модель и одна ревизия; три коротких текста (172–233 токена), батч 1.
 - Режимы fp16_upcastQK и fp64_true — контрольные конструкции, а не штатные конфигурации.
 - M — диагностическая величина; ни одно определение w_min не выделено как каноническое.
